# Icon Placeholders

The extension requires icons in the following sizes:
- icon16.png (16x16)
- icon32.png (32x32)
- icon48.png (48x48)
- icon128.png (128x128)

## Quick Icon Creation Options

### Option 1: Using an online tool
Visit https://www.favicon-generator.org/ to create icons from an image or design.

### Option 2: Using a placeholder service
For testing, you can create simple colored squares:

1. Visit https://via.placeholder.com/
2. Generate:
   - https://via.placeholder.com/16/FF0000/FFFFFF?text=TQ
   - https://via.placeholder.com/32/FF0000/FFFFFF?text=TQ
   - https://via.placeholder.com/48/FF0000/FFFFFF?text=TQ
   - https://via.placeholder.com/128/FF0000/FFFFFF?text=TQ

### Option 3: Design suggestion
Create icons featuring:
- Red/white color scheme (matching YouTube branding)
- Queue or playlist symbol
- "TQ" initials
- Film strip or video camera icon

## Temporary Workaround

Until proper icons are created, you can:
1. Use any .png files renamed to the correct sizes
2. The extension will still load, but icons won't display properly
3. Chrome may show a default placeholder icon
